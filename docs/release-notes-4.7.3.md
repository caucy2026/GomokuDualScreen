# 4.7.3 上架说明

包名 `com.gomoku.dualscreen`　｜　versionName **4.7.3**　｜　versionCode **7**　｜　minSdk 31 / targetSdk 34
全部改动见 [CHANGELOG.md](../CHANGELOG.md)，双屏适配规则见 [dual-screen-app-guide.md](dual-screen-app-guide.md)。

## 商城更新文案（可直接粘贴）

**本次更新**

- 修复双屏切换后玩家归属错乱：按固件交换状态自动判定黑/白方所在屏，开关屏幕交换后不再串屏。
- 修复画面朝向：转动设备、开关屏幕交换后画面不再整体倒置。
- 修复退出：任意一侧返回/侧滑退出，两侧窗口一起关闭，不再残留“等待双屏就绪”。
- 修复少数机型上画面反复闪“等待双屏就绪”。
- 统一“重新开始 / 悔棋 / 退出”确认弹窗，两块屏样式一致。
- 对局进度、回合、提子数持久化，杀进程后重新打开可继续。

**已知限制**

- 屏幕交换由系统开关控制，应用只读取、不修改。
- 竖持（90°/270°）姿态未做适配，当前按 0°/180° 处理。
